# DevBoard 🚀  
Project Management Dashboard

DevBoard — это современное frontend-приложение для управления проектами и задачами, вдохновлённое Jira, Linear и Notion.  
Проект создан как pet-project для демонстрации навыков Frontend разработчика.

🌐 **Live demo:** https://devboard-demo.vercel.app  
💻 **GitHub:** https://github.com/username/devboard

---

## ✨ Features

- 🔐 Авторизация (mock auth)
- 📋 Управление проектами (CRUD)
- 🧱 Kanban board (Todo / In Progress / Done)
- 🖱 Drag & Drop задач
- 📝 Модалка задачи (редактирование, приоритеты)
- 📊 Dashboard с аналитикой
- 🌙 Light / Dark mode
- 📱 Полная адаптивность
- 🎬 Анимации (Framer Motion)
